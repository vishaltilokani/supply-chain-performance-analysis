
# Supply Chain Performance Analysis

## Project Overview
An end-to-end supply chain analytics project analyzing delivery performance, profitability, operational bottlenecks, and late-delivery risk using the DataCo Supply Chain Dataset.

## Objectives
- Analyze on-time and late delivery performance.
- Evaluate order profitability and financial impact of delays.
- Identify operational bottlenecks across shipping modes and regions.
- Perform root cause analysis of late deliveries.
- Build a machine learning model to predict late-delivery risk.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- SMOTE (imbalanced-learn)
- Random Forest
- Google Colab

## Key Results
- Orders analyzed: 172,765
- Late delivery rate: 54.71%
- On-time delivery rate: 45.29%
- Total profit: $7.5M
- Profit at risk: approximately $2.1M
- Random Forest accuracy: 74%

## Project Workflow
1. Data cleaning and preprocessing
2. Exploratory data analysis
3. KPI and profitability analysis
4. Bottleneck detection
5. Regional root cause analysis
6. Time-based delay analysis
7. Machine learning with SMOTE and Random Forest
8. Strategic recommendations
